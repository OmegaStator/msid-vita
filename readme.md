# My Shut-in Demon for Playstation® Vita

Thanks to MrJack for this great game

## How to install
### Manual installation
- Download the vpk file from the release tab
- Move the file to your console and install it using VitaShell
- After installing the game, put the "game" folder from the base game in ux0:/app/RNPYMSID2/game
    - Note : the releases are aligned with free chapiter releases, paid chapiters might not work
- Enjoy !
